What The Func

Turns a diff into plain English, so anyone can review what changed and why.

src/auth/login.ts
import { db } from '../db';
import bcrypt from 'bcrypt';
const user = await db.find(email);
if (!user) throw new AuthError();
const ok = await bcrypt.compare(
password, user.hash);
if (!ok) throw new AuthError();
Passwords are now checked against a secure hash.
A wrong email and a wrong password show the same “Invalid credentials” message.
